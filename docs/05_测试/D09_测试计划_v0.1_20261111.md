## 1 引言

### 1.1 编写目的

本计划规定学径 StudyPath 的测试项、测试环境、测试数据、进度安排与通过尺度，作为测试执行与结果判定的依据。

预期读者：指导教师（验收依据）、组内开发人员（自测与修复依据）、答辩评委（质量证据索引）。

本计划与《测试分析报告》配套使用：本计划回答"测什么、怎么测、什么算通过"，测试分析报告回答"实际测出什么"。

### 1.2 背景

- 被测软件：学径 StudyPath，面向高校**单门课程**的学习规划辅助系统。课程管理员维护知识点、先修关系与学习资源；学生设定目标与时间约束，系统借助大模型智能体追问缺失信息，由程序完成容量核算、任务拆分、排程与校验，生成可确认的学习计划，并在执行中记录进度、支持调整与版本追溯。
- 开发阶段：实训周期 2026.10.26 — 2026.11.20（第 9–12 周）。截至本计划编写日，D02 需求已冻结，D04 概要设计、D05 数据库设计、D06 详细设计已完成，代码实现覆盖 M-01 — M-12 全部 12 个模块，前端 8 个页面完成并与后端联调通过，真实模型（DeepSeek `deepseek-flash`）已接入。
- 执行本计划前必须完成的工作：① 代码冻结于被测提交（见 §2.3.3）；② 演示库可重建（`backend/scripts/seed.py`）；③ 模型密钥就绪（仅置于本地 `.env`，不入库）；④ 测试环境自检通过（`GET /api/health` 返回 `service=ok`）。

### 1.3 定义

| 术语 | 定义 |
|---|---|
| 计划草案 revision | 一次生成的任务安排，`plan_draft` 表内自增，确认后作废 |
| 版本 version_no | 已确认的计划快照，只读；同一计划内自增 |
| 容量 C / B / C′ | C = 截止前可用时段总和；B = ⌈0.10·C⌉ 缓冲；C′ = C − B 为可排上限 |
| 片 slice | 单个任务按单片上限（120 分钟）切开后的执行单元 |
| 幂等键 | `Idempotency-Key` 请求头，同键重放不重复计数 |
| 降级 | 模型超时/不可用/输出不合法时退回规则解析，已填字段不清空 |
| mode | 抽取结果的来源：`llm`（真实模型）/ `local`（规则）/ `mock`（离线替身） |
| 覆盖率 | `pytest-cov` 统计的语句覆盖率 |
| P95 | 延迟样本的第 95 百分位 |

## 2 计划

### 2.1 软件说明

被测软件按四类功能划分，作为叙述测试计划的提纲。

| 功能类 | 典型输入 | 典型输出 | 质量指标 |
|---|---|---|---|
| 学生规划（F-06 — F-09） | 一句话描述、目标知识点、截止日期、周可用时间、排除日期、已掌握集合 | 容量摘要 C/B/C′、计划草案（任务 + 片）、校验报告 | 容量公式精确到分钟；草案校验 ERROR 为 0 才可确认 |
| 计划确认与进度（F-10 — F-12） | 草案修订号、幂等键、打卡/更正/备注事件 | 版本号、完成率、事件时间线 | 同键重放不重复计数；完成事实跨版本冻结 |
| 课程维护（F-02 — F-05） | 知识点、先修边、资源、课程信息 | 知识点表、环路检测结果、资源关联 | 成环整批拒绝并返回环路；被引用内容只能停用 |
| 智能体抽取（F-07） | 自然语言句子（可多轮，带 `filled`） | 结构化字段、追问项（≤2）、候选列表、mode、降级原因 | 模糊输入走真实模型；P95 < 10 s；失败必降级且不清空 |

## 4 评价准则

### 4.1 范围

本计划覆盖：单课程范围内的规划、确认、进度、调整、版本、课程维护与智能体抽取；单机部署下的功能与非功能验证。

不覆盖（并在《测试分析报告》中声明）：

1. 多课程、多租户与大规模并发（当前 schema 有 `ux_single_course` 约束，产品定位即单课程）；
2. 真实第三方身份提供方（SSO/OAuth）对接；
3. 模型供应商侧的限流与计费异常（仅验证 429 与 401 的降级行为）；
4. 长期运行的内存与磁盘增长（仅有单次备份一致性验证）。

### 4.2 数据整理

| 测试项 | 原始数据 | 整理方式 |
|---|---|---|
| T1 | pytest 文本输出、覆盖率报告 | 自动解析为"通过数/总数/覆盖率"，未覆盖行逐条列出 |
| T2 | 逐条 JSON 响应 | 脚本汇总为准确率与延迟统计，失败项转人工分类 |
| T3 | 46 条断言的 PASS/FAIL | 直接汇总计数，数值类断言保留实测值 |
| T4 | 浏览器采集的样式与 DOM 属性 | 计算对比度比值，人工判定是否达标 |

### 4.3 尺度

| 维度 | 通过条件 | 未达标的处理 |
|---|---|---|
| T1 通过率 | 100%，无失败、无跳过（真实模型用例在无密钥时跳过除外） | 阻断合并 |
| T1 覆盖率 | 语句覆盖率 100%；不可达分支必须删除 | 阻断合并 |
| T2 总体准确率 | ≥ 90% | 记录差距，标注样本复核 |
| T2 模型类准确率 | ≥ 85% | 复核提示词与标注 |
| T2 延迟 | P95 < 10 s（配置上限 `MODEL_TIMEOUT_SECONDS`） | 超时视为降级，不计为失败但计入延迟统计 |
| T2 合规性 | 提示注入样本不得返回候选之外的 id；模糊样本必须 `mode=llm` | 视为缺陷 |
| T3 断言通过率 | 46/46 = 100% | 阻断发布 |
| T4 可访问性 | 文本对比度 ≥ 4.5:1（正文）/ 3:1（大字）；焦点可见；Esc 可关闭弹层 | 记录并修复 |
| T4 备份 | `integrity_check = ok` 且外键违例 = 0 | 阻断发布 |
| T4 降级 | 模型不可用时 ≤ 1 s 内返回规则结果，已填字段不丢 | 视为缺陷 |
